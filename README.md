# AI-Powered Integrated Infrastructure Project Monitoring Platform (SIH26103)

## 📌 Problem Statement Overview
Developed for the Ministry of Statistics and Programme Implementation (MoSPI) to monitor Central Sector Infrastructure Projects, predict schedule delays using machine learning, explain root causes, and accept digital progress reports from contractors.

## 🚀 Key Modules
1. **Government Officer Reviewer Dashboard:** ML risk prediction radar and "What-If" intervention simulator.
2. **Contractor Progress Submission Portal:** Allows contractors to submit monthly progress metrics directly into the ML analysis pipeline.
3. **User Registration & Role-Based Portal:** Integrated account creation for Officers, Contractors, and Site Engineers.

## 🛠️ Stack
- **Backend:** Flask (Python)
- **Database:** SQLite / PostgreSQL
- **Frontend:** HTML5, Tailwind CSS, JavaScript
